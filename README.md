# Anushka Singhee — Personal Portfolio

Static portfolio website for software engineering, data science, artificial intelligence and robotics work.

## Local preview

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

This repository should be named `Anushka0707.github.io`. GitHub Pages publishes the `main` branch from the repository root.

Contact and profile values are stored in `site-config.js`.
